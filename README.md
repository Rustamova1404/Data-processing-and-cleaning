# Лабораторная работа №1: Предобработка и очистка данных

**Выполнила:** Рустамова Азиза
**Датасет:** dirty_employees.csv

## Описание работы
В ходе лабораторной работы был проведен аудит и очистка набора данных о сотрудниках. 
Основные этапы:
1. Приведение типов данных (строки в числа и даты).
2. Поиск и удаление полных и частичных дубликатов.
3. Заполнение пропусков (медианой для чисел и модой для категорий).
4. Поиск и обработка выбросов (методы IQR и Z-score).
5. Визуализация данных (ящиковые диаграммы, тепловые карты).
6. Мини-кейс: симуляция "грязных" данных и их восстановление.

## Результаты
* Исходный размер датасета: 305 строк.
* После удаления дубликатов: 300 строк.
* Исправлены некорректные значения.
